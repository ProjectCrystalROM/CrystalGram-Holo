# The CrystalGram Philosophy

## Old hardware is not obsolete by decree

A device does not become useless simply because its manufacturer has stopped supporting it.

CrystalGram exists to extend the practical usefulness of older Android devices through modern protocol implementations, maintained cryptographic libraries, and software designed around their actual capabilities.

Hardware should retire when its owner decides it should, not when a corporation decides it is no longer commercially interesting.

## Native means native

CrystalGram does not attempt to disguise older Android releases as modern ones.

Holo belongs on Jelly Bean. Gingerbread belongs on Gingerbread. The operating system provides its own visual identity, widgets, menus, and interaction conventions.

Chrome belongs to Android. Bubbles belong to CrystalGram.

## Messaging, not cryptocurrency

CrystalGram takes an explicitly anti-cryptocurrency stance.

We reject the increasing integration of cryptocurrency speculation, token economies, blockchain services, and their associated advertising into otherwise useful communication platforms.

A messaging application should facilitate communication between people. It should not serve as a gateway into speculative financial ecosystems.

CrystalGram will not introduce cryptocurrency integrations, wallets, token-based monetisation, or cryptocurrency advertising infrastructure.

## Principled exclusion over deceptive implementation

CrystalGram respects Telegram's API requirements while making deliberate decisions about its own functional scope.

Rather than implement broadcast channels and strip their required sponsored messages, CrystalGram excludes broadcast channels entirely. Private bot conversations are similarly outside the application's current scope.

These are conscious architectural decisions, not attempts to circumvent advertising requirements.

Broadcast channel support is not planned for future releases.

## Privacy is a responsibility

Supporting older hardware does not justify disregarding user privacy.

Privacy settings, notification visibility, message expiration, session management, and other supported privacy mechanisms must behave as expected.

Features whose security requirements cannot be responsibly implemented should not be advertised as supported.

## Compatibility without pretence

CrystalGram does not promise complete feature parity with Telegram's official applications.

Platform limitations, unsupported functionality, and unverified compatibility must be documented honestly. A successful compilation is not proof of compatibility, and a successful connection is not proof of security.

## Software belongs to its users

CrystalGram's own source code is distributed under the GNU General Public License, version 3.

Users should be able to inspect, modify, rebuild, and redistribute the software under the terms of its licence.

Preservation is a collaborative effort. Contributions that respect the project's technical and philosophical principles are welcome.

---

*Preserve the hardware. Respect the platform. Protect the conversation.*
